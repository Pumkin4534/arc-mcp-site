# Arc MCP — compatibility entry points

The canonical website is now **https://pumkin4534.github.io/**, maintained in
[`Pumkin4534/Pumkin4534.github.io`](https://github.com/Pumkin4534/Pumkin4534.github.io).

This repository keeps previously shared addresses working:

- `/arc-mcp-site/` redirects visitors to the main website.
- `/arc-mcp-site/install.sh` downloads and invokes the canonical main-site installer.

Website and platform-installer changes belong in the canonical repository. The
remaining earlier assets/history here are retained for compatibility and reference.
No MCP runtime state, credentials, or configuration backups belong in this repository.
